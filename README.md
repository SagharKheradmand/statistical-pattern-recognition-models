
# Statistical Pattern Recognition Homework 1

## Overview

This project contains four machine learning assignments for the Statistical Pattern Recognition course.

The project covers:

- Linear Regression on the Auto MPG dataset
- Binary Logistic Regression on the Bank Marketing dataset
- Multiclass Logistic Regression on the Wine dataset
- Ridge Regression for studying regularization and multicollinearity

Most models are implemented and evaluated in Jupyter Notebook using Python and NumPy. :contentReference[oaicite:0]{index=0}

## Main Methods

- Linear Regression
- Batch and Stochastic Gradient Descent
- Binary Logistic Regression
- One-vs-All and One-vs-One Classification
- Softmax Regression
- Ridge Regression
- Data Preprocessing and Visualization
- Model Evaluation

## Notebooks

- `1.ipynb` — Linear Regression
- `2.ipynb` — Binary Logistic Regression
- `3.ipynb` — Multiclass Classification
- `4.ipynb` — Ridge Regression :contentReference[oaicite:1]{index=1}
